# New feature - results analyzer
## Context
- This application now provides payment samples
- This application also labels them (bad actors, good actors)
- Users use payments generated by this app to input them in sanctions screening system and produce "screening results"

## New feature context
- Now this app has to be able to load any type of screening result .csv (see below for specific requirements)
- This app has to support loading in the "bad actors list item" list from .csv (despite that it does produce it by itself, still needs support for sideloading)
- This app has to use the results and bad actors list items to generate "confusion matrix"
- This app also has to calculate accuracy, precision given the calculated confusion matrix
- In context of previous feature, this feature has also give breakdown of TP,FP,TN,FN values grouped by sample tags
- Also produce accuracy, precision and F1 score results calculated from confusion matrices for each "tag" type

## UI
- Separate tab "Analyze results"

## Functionality
- Upload "results file" .csv (variable schema: any schema provided by another system, only tabular row based results where 1 row = 1 payment and result)
- Configure "match conditions" (use something like react-queryBUilder) as these must include but not be limited to equals_to, greater_than. Also it needs custom fuctions for example getBadActor(paymentId) to dynamically retrieve something between used datasets. See resultReader.ts code stubs for ideas / context
- Upload "bad actor list item" .csv file (strict schema: actor_id, value, payment_id, message_id)
- Using match conditions, assign True positive, false positive, true negative, false negative labels
